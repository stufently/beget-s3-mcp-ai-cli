# Обмен файлом

Если capabilities.presign:false, не вызывай presign: запроси у владельца ссылку из панели или используй разрешённое скачивание. Следующие инструменты доступны только при presign:true.

`s3_presign_get` выдаёт ссылку на разрешённый ключ; укажи срок не выше 604800 секунд. Ограничение профиля может требовать живой проверки: Панель Beget создаёт ссылки максимум на 7 дней; потолок внешнего SigV4 GET/PUT не установлен, инструменты presign выключены. Bucket API — только панель; нужна живая проверка.. Не записывай подпись в журналы. `s3_presign_put` может перезаписать объект и всегда требует подтверждения.
