# Минимальные права

Владелец выдаёт агенту S3-ключи и права пользователя/роли в Beget; точные команды управления пользователями эта версия не предоставляет. Не придумывай процедуру выдачи роли: сверь её с актуальной панелью владельца. Используй политику бакета только при её наличии в capabilities. Дополнительно ограничь сервер ALLOWED_BUCKETS и ALLOWED_PREFIXES; оставь только read, включай write/delete/admin независимо по необходимости. Частичный скоуп не допускает операции над всем бакетом. Секрет хранится в приватном файле credentials, не в конфиге агента.
