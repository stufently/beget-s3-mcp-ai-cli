# Бэкап и восстановление

Выбери разрешённый бакет и префикс. Получи список и метаданные, затем загрузи локальный файл через файловый инструмент либо CLI `cp`; для больших файлов используется multipart. Перезапись требует согласия. Сверь размер и контрольную сумму собственной копии после восстановления. Если versioning включён в capabilities, версии можно просмотреть и восстановить явным чтением version_id. Перед удалением версии предупреди о необратимости.
